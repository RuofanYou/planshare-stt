# STT 写作能力地图

根据玩家想达到的结果选择写法。向玩家一次推荐 3–5 项与当前 Boss 有关的能力，并明确最值得先做的一项。

## 团长常用目标

| 玩家目标 | STT 能力 | 需要确认 |
|---|---|---|
| 标出 Boss 技能并安排全团口令 | 内置模板、`{BOSS}`、`{所有人}` | Boss、难度、需要播报的机制 |
| 安排团队减伤、治疗技能或爆发轮次 | `[人员]` 槽位、职业技能、`{spell:ID}` | 名单、专精、技能轮次 |
| 同一机制给不同人不同指令 | 一行多个受众片段；行级效果不同时拆行 | 谁收到什么文字、是否需要不同提前量 |
| 按职责、职业、专精或小队提醒 | 受众条件与组合条件 | 需要“或”还是“同时满足” |
| 转阶段后按相对时间提醒 | 阶段时间、阶段轮次、`[设置]` | 阶段来源和实际进入顺序 |
| 技能前播放数字倒数 | `{ct:N}` | 倒数长度 1–10 |
| 提前显示屏幕提醒 | `{sr:N}`、`{to:名称}` | 接收端已有的指示器名称 |
| 显示技能持续区间 | `{dur:N}` | 持续时间来源 |
| 显示分段进度 | `{bar:...}` | 各段长度、方向、标签和图标 |
| 提醒一串技能顺序 | `{tl:...}` 或 `{tl:end:...}` | 正推或倒推、各技能 ID |
| 播放本地音效 | `{@文件名或路径}` | 每台接收端都存在的资源 |
| 播放站位或走位画板 | `{board:名称}` | 接收端已有的画板名与起播时间 |
| 长期显示站位和分工 | `[便签]` | 便签内容和可见范围 |
| 保存 20 人进本名单 | `[阵容]` | 1–20 号位与人员映射 |
| 盘卷祭坛安排打断轮替 | `[打断]`、`[P3打断]` | P2/P3 两行名单及遗漏人员行为 |

## 普通玩家常用目标

| 玩家目标 | STT 能力 | 需要确认 |
|---|---|---|
| 只提醒自己的走位、减伤或爆发 | 个人方案、无受众事件 | Boss、难度、职业专精、机制 |
| 用自己的技能替换团队安排 | 个人覆盖、主技能 Spell ID | 要覆盖的技能和共享提示是否需保留 |
| 只看提示，不播放语音 | `~~文字~~`、纯视觉效果 | 仍需显示的文字或图标 |
| 看见技能图标和名称 | `{spell:ID}` | Spell ID 来源 |
| 在技能前获得更早提示 | 行内提前量或屏幕提前量 | 想提前几秒、作用于声音还是屏幕 |

## 修改和转换

- 修复现有 STT：先保留原始事实，再处理括号、区块、受众、槽位、时间和行级参数问题。
- lorrgs：可将导出的时间轴加上 `[人员]` 后使用。
- NSRT、MRT：先按完整指南中的转换规则处理，再核对多人受众、阶段映射和被丢弃字段。
- 玩家只描述结果：先推荐最小可用方案，再询问真正阻止生成的事实。

## 按 Boss 推荐能力

- 模板出现多次全团伤害：优先推荐减伤/治疗技能轮次和屏幕提前提醒。
- 模板存在阶段相对时间：优先推荐阶段提醒，并要求确认阶段来源。
- 同一时刻有多种职责：优先推荐受众分段；效果参数不同时提醒拆行。
- 机制需要连续操作：推荐 TL；持续窗口明显时推荐 `dur` 或 `bar`。
- 站位、路径或多人位置关系难以用一句话说明：推荐画板或便签。
- 模板只提供 Boss 技能参考：先完成最少的关键口令，不为每个技能自动添加语音。

没有实际机制依据时不要推荐画板、音效、阶段或特定职业技能。
